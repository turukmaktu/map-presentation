# Форма обратной связи: reCAPTCHA v3 → Google Sheets

```
Сайт (GitHub Pages) ──данные + token──▶ Apps Script (web app) ──▶ проверка reCAPTCHA
                                               └──▶ строка в приватной Google-таблице
```

Секретный ключ хранится только в Apps Script. В репозиторий и GitHub попадают лишь публичные значения.

## 1. Google-таблица

1. Создайте таблицу на https://sheets.new (например, «Landing feedback»).
2. Никому её не расшаривайте — по умолчанию доступ только у вас.
3. (Опционально) **Инструменты → Настройки уведомлений → Правила уведомлений** — письмо на почту при каждой новой заявке.

## 2. Ключи reCAPTCHA v3

1. Откройте https://www.google.com/recaptcha/admin/create.
   Если консоль попросит выбрать проект Google Cloud — создайте/выберите любой, бесплатного лимита хватит с запасом.
2. Тип: **reCAPTCHA v3 (на основе оценки)**.
3. Домены:
   - `turukmaktu.github.io`
   - `localhost` (для локальной разработки)
4. Сохраните. Получите два ключа:
   - **Site key** (ключ сайта) — публичный, пойдёт в GitHub;
   - **Secret key** (секретный ключ) — только в Apps Script, никуда больше.

## 3. Apps Script

1. В таблице: **Расширения → Apps Script**.
2. Удалите содержимое `Code.gs` и вставьте код из [`apps-script/Code.gs`](../apps-script/Code.gs). Сохраните (Ctrl+S).
3. Слева **⚙ Настройки проекта → Свойства скрипта → Добавить свойство**:
   | Свойство | Значение |
   |---|---|
   | `RECAPTCHA_SECRET` | Secret key из шага 2 |
   | `ALLOWED_HOSTNAMES` | `turukmaktu.github.io,localhost` |
   | `MIN_SCORE` | `0.5` (необязательно) |
4. Вернитесь в редактор, в выпадающем списке рядом с кнопкой **Выполнить** выберите функцию **`setup`** и нажмите **Выполнить**.
   (Не `doPost`: её вызывает только веб-приложение, при ручном запуске будет ошибка `Cannot read properties of undefined (reading 'postData')`.)
   Google попросит разрешения → выберите свой аккаунт → «Дополнительные настройки» → «Перейти к проекту (небезопасно)» → «Разрешить».
   Это ваш собственный скрипт, предупреждение стандартное. В таблице появится лист `Feedback` с заголовками.
5. **Начать развертывание → Новое развертывание** → ⚙ «Выберите тип» → **Веб-приложение**:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
6. **Развернуть** → скопируйте **URL веб-приложения** (оканчивается на `/exec`).

> «Доступ: Все» относится только к приёму POST-запросов. Таблица остаётся приватной: скрипт пишет в неё от вашего имени, а читать её никто, кроме вас, не может.

**Если меняете код скрипта:** Развертывание → Управление развертываниями → ✏ → Версия: **Новая версия** → Развернуть. URL останется прежним.

## 4. GitHub

Репозиторий → **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**:

| Name | Value |
|---|---|
| `VITE_RECAPTCHA_SITE_KEY` | Site key из шага 2 |
| `VITE_FEEDBACK_ENDPOINT` | URL `/exec` из шага 3 |

Именно *Variables*, не *Secrets*: оба значения публичные и всё равно оказываются в JS-бандле.

Затем **Actions → Deploy to GitHub Pages → Run workflow** (или любой пуш в `main`).

## 5. Локальная разработка

```sh
cp .env.example .env.local   # и заполните те же два значения
npm run dev
```

## Защита

- reCAPTCHA v3: проверяются `success`, `action === "feedback"`, `score ≥ MIN_SCORE`, hostname.
- Honeypot-поле `website` — боты, заполнившие его, молча отбрасываются.
- Длины полей обрезаются; значения, начинающиеся с `= + - @`, экранируются (защита от formula injection в Sheets).
